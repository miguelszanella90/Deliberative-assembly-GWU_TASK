# Deliberative Assembly — Continuous Inductive Learning Pilot

Self-contained, mobile-responsive, static HTML game for a proposed controlled experimental research design.

## Research question

What is the effect of continuous inductive learning on collective reasoning and decision-making among randomly assigned participants in controlled, scheduled deliberative sessions, where reasoning capacities, communication opportunities, and power relationships vary under conditions of time pressure and uncertainty?

## Start the game

Open **index.html** in a browser or visit the published GitHub Pages URL. The game has no external dependencies or backend. On narrow screens, use the **Game board / Assembly table / Both** switch, in portrait or landscape orientation.

## Publish on GitHub Pages

1. Create a new public GitHub repository (for example `deliberative-assembly-pilot`).
2. Upload all repository files here, keeping `index.html` at the repository root.
3. In your repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main**, folder **/(root)**, and save.
5. Your public game URL will ordinarily be `https://YOUR-USERNAME.github.io/deliberative-assembly-pilot/`. Use that link in the research pitch and appendix after GitHub confirms deployment.

## Files

- `index.html` — primary website and game (self-contained).
- `game.html` — optional identical standalone copy.
- `APPENDIX_GAME_RULES.md` — copy-ready rules and experimental protocol.
- `README.md` — repository description and publishing instructions.
- `.nojekyll` — prevents special Jekyll processing of a plain static site.

## Data privacy and persistence

Game data are stored locally in the playing browser and exported manually. GitHub Pages **does not collect, sync, or centrally store participant data**. Browser storage is tied to the site origin and may be erased by browser or privacy settings. Download research exports regularly. The mobile view switch changes display only, never the experimental condition or logged decisions.

## Research scope

In the assisted pilot, P1 is human and nine participants are simulated. Low/high information sessions alternate for testing; the proposed human experiment instead randomly assigns independent assemblies to conditions. Source documents are fictional research stimuli, not real scholarly citations.
